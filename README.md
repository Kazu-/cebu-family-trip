# 🌴 セブ島 家族旅行 2027

12名・福岡＋成田 2空港発／2027年夏（4泊5日、現地3日間）の家族旅行サイト。
ホテルは **シャングリ・ラ マクタン セブ** に確定。
GitHub Pages: <https://kazu-.github.io/cebu-family-trip/>

## 構成

| パス | 役割 |
|------|------|
| `index.html` | **ホーム（ハブ）**。確定内容サマリ（ホテル・フライト・予算）と各ページへの入口。`plans-data.js` から自動生成 |
| `plans-data.js` | **確定内容の唯一の情報源**。`CEBU.confirmed` にホテル・フライト・予算等を定義 |
| `guide.html` | **詳細ガイド（旅のしおり）**。航空券・ホテル情報・5日間日程・アクティビティ・食事・持ち物・雨の日・緊急連絡先・予約時系列 |
| `wbs.html` | 準備タスクの管理ページ（Googleスプレッドシート埋め込み） |
| `styles.css` | 共通スタイル |
| `proposal-original/` | **検討初期に作成したパンフレット（保存版）**。ホテル・日程は現在の確定内容と異なる旧原案として保持 |

## 確定内容を編集する

`plans-data.js` の `CEBU.confirmed` オブジェクトを編集すると、ホームの確定サマリ・予算表に自動反映されます。
日程・ホテル比較・アクティビティ等の本文は `guide.html` を直接編集します。

## 旧プラン案との関係

- 検討段階ではプランA（コスパ重視）／B（バランス・採用）／C（贅沢）を比較していましたが、
  ホテル・日程確定に伴いプラン比較機能（`plan.html` 等）は削除し、確定内容のみを掲載する構成に変更しました。
- 旧パンフレットは `proposal-original/index.html` として引き続き保存（URL: `/proposal-original/`）。
